# Book Sales Exploratory Data Analysis (EDA)

A quick data analysis project to uncover sales patterns in the book industry. This EDA explores trends related to genre, author ratings, and publishing years.

### Dataset

The dataset for this analysis is a cleaned collection of book sales data. It can be found on Kaggle, and similar datasets are widely available for public use.

### Key Findings

- **Sales Growth:** A clear upward trend in total units sold is observed over the years.
- **Top Genres:** The analysis identifies which book genres consistently perform best in the market.
- **Author Impact:** Investigated the correlation between an author's rating and the number of books sold.

### Tech Stack
- Python
- Pandas
- Matplotlib
- Seaborn
